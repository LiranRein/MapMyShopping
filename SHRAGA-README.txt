שרגא - ארכיטקט ה-AI של LetsAI ל-Claude Code
==============================================

שרגא הוא ארכיטקט תוכנה שעובד בתוך Claude Code, בתיקיית הפרויקט שלכם.
הוא מאפיין את המוצר, קובע את הארכיטקטורה, מפרק את הפיתוח לפאזות, כותב לכם פרומפט מוכן לכל פאזה - ומוודא שמה שנבנה תואם למה שתוכנן.
הוא לא כותב את הקוד בעצמו: את זה עושה סשן בנייה נפרד, ובסוף כל פאזה בודק עצמאי מאשר או דוחה.


מה צריך לפני שמתחילים
----------------------
- Claude Code מותקן ומחובר.
- ב-Windows: Git for Windows מותקן (Claude Code צריך אותו בכל מקרה).


התקנה - פעם אחת לכל פרויקט
---------------------------
1. העתיקו את כל התוכן של התיקייה הזו לתיקיית השורש של הפרויקט שלכם:
     CLAUDE.md
     SHRAGA-README.txt
     .claude   (תיקייה שמתחילה בנקודה - חובה להעתיק גם אותה)
     shraga
   ב-Mac, ה-Finder מסתיר תיקיות שמתחילות בנקודה. לחצו Cmd + Shift + . כדי לראות את .claude

2. כבר יש לכם בפרויקט CLAUDE.md או .claude/settings.json? אל תדרסו אותם - ראו "שאלות נפוצות" למטה.

3. פתחו את Claude Code בתיקיית הפרויקט. בפעם הראשונה הוא ישאל אם אתם סומכים על התיקייה - אשרו.

4. כתבו /shraga

אין צורך ליצור שום קובץ נוסף:
- shraga/PHASE.md כבר קיים ומוגדר לפאזה 0.
- CLAUDE.md הוא ה"חוקה" של שרגא - לא יוצרים אותו מחדש ולא משנים אותו.


איך עובדים
-----------
א. /shraga - שרגא מסביר את התהליך ומתחיל באפיון (PRD).
ב. שרגא בונה תוכנית פאזות (Plan.md).
ג. לכל פאזה:
   1. שרגא כותב פרומפט לפאזה.
   2. מעתיקים אותו, פותחים סשן חדש של Claude Code באותה תיקייה, ומדביקים.
   3. סשן הבנייה בונה את הפאזה ומריץ בדיקות.
   4. בסוף, סשן הבנייה מפעיל את הבודק העצמאי (/shraga-review), שמאשר או דוחה.
   5. אחרי אישור - חוזרים לסשן של שרגא וכותבים "סיימתי". שרגא סוגר את הפאזה ועובר לבאה.
ד. הפאזה האחרונה: מוכנות לפרודקשן (בדיקת אבטחה ובדיקות מלאות).

שלושה סוגי עבודה:
- סשן שרגא: כאן מתכננים. פותחים עם /shraga. אפשר לסגור ולפתוח חדש בכל רגע - שרגא ימשיך מאיפה שעצרתם.
- סשן בנייה: סשן חדש באותה תיקייה, שבו מדביקים את הפרומפט של הפאזה. סשן חדש לכל פאזה.
- הבודק: /shraga-review. רץ לבד בסוף הפאזה. הוא לא ראה את השיחה שבנתה את הקוד, ולכן הוא בודק באמת.


שתי פקודות ושאלה אחת
---------------------
/shraga             להתחיל, או לחזור לשרגא בכל שלב.
/shraga-review      בסוף פאזה, בסשן הבנייה (בדרך כלל רץ לבד).
"מה עושים עכשיו?"   בכל רגע, בכל סשן - הסוכן יבדוק איפה אתם ויגיד מה הצעד הבא.


איפה הכל נשמר
--------------
כל מסמכי שרגא נמצאים בתיקייה shraga, בנפרד מהקוד:
- PHASE.md - באיזו פאזה אתם עכשיו. שרגא מעדכן אותו, לא אתם.
- project-arch-plan.md - מסמך האפיון והארכיטקטורה (PRD).
- Plan.md - תוכנית הפאזות והסטטוס של כל פאזה.
- DESIGN_SYSTEM.md - ספר החוקים העיצובי (אם יש ממשק).
- phase-N-plan.md - תוכנית מפורטת לפאזה מורכבת (לפי בקשה).
- prompts - עותק של כל פרומפט ששרגא נתן.
- reports - הדוח של סשן הבנייה על כל פאזה.
- reviews - פסק הדין של הבודק על כל פאזה.


שאלות נפוצות
-------------
כבר יש לי CLAUDE.md בפרויקט.
  ה-CLAUDE.md של שרגא חייב להיות בשורש. העבירו את התוכן שלכם (פקודות, מוסכמות) לקובץ .claude/rules/project.md ואז העתיקו את של שרגא. Claude Code קורא את שניהם.

כבר יש לי .claude/settings.json.
  אל תדרסו אותו. העתיקו מהקובץ של שרגא את הבלוק "hooks" לתוך הקובץ הקיים שלכם.

הבודק דחה פעמיים.
  זה בכוונה: סשן הבנייה עוצר. חזרו לסשן של שרגא וספרו לו - הוא יחליט אם לתקן את הקוד או את התוכנית, ויכין פרומפט תיקון.

השיחה עם שרגא נהייתה איטית וכבדה.
  פתחו סשן חדש וכתבו /shraga. כל ההחלטות נשמרות בקבצים, כך ששום דבר לא הולך לאיבוד.

איבדתי את הפרומפט.
  הוא שמור בתיקייה shraga/prompts. או פשוט שאלו "מה עושים עכשיו?" - הסוכן יציג אותו שוב.

אפשר לדלג על שלבים?
  אפשר להתחיל מכל נקודה בתפריט של שרגא, כולל בדיקה של פרויקט שכבר התחלתם.
  אבל שרגא ממליץ על הסדר: PRD, אחר כך Plan.md, ואז פאזה אחרי פאזה.
  One Shot קיים ומתאים לדמו - לא למוצר עם משתמשים אמיתיים.
